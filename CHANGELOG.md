# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-03-08

### Added
- Initial release
- Web search using Kimi API's `$web_search` builtin_function
- Support for Chinese and English queries
- Command-line interface
- Python API for integration
- Token usage reporting
- OpenClaw Skill packaging

### Features
- Real-time web search
- AI-synthesized results with citations
- Environment variable and file-based API key configuration
- Error handling and retry logic
